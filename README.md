- **Live Position Updates**: See Santa's current location update in real-time using the Google Santa Tracker API.
- **Flight Path Display**: Get details on the last 5 cities Santa visited and the next 5 destinations.

- **Sleigh Performance Metrics**: View speed (6,500-6,950 mph), altitude (~60,000 ft), and weight tracking.
